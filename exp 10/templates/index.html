Exploratory Data Analysis (EDA)

Actual visualizations generated from the dataset using Matplotlib and Seaborn, illustrating class distribution, feature relationships, separability, and correlation.

1. Species Distribution

Confirms a balanced distribution with exactly 50 samples for each species (Setosa, Versicolor, and Virginica).

2. Sepal Dimensions (Length vs Width)

Sepal measurements exhibit moderate overlap between Versicolor and Virginica, while Setosa tends to have wider sepals.

3. Petal Dimensions (Length vs Width)

Key insight: Petal dimensions offer clear linear separability for Setosa and strong clustering distinction for Versicolor and Virginica.

4. Measurement Distributions (Boxplots)

Compares medians, quartiles, and spreads for all four morphological characteristics across the three taxa.

5. Correlation Heatmap (Pearson r)

Model Training, Feature Scaling & K-Selection

A reproducible, stratified train-test split combined with Scikit-learn's StandardScaler and KNeighborsClassifier.

Train-Test Split (80% / 20%)

Stratified by class to preserve equal 1:1:1 representation in both sets:

  • Training Set: {{ metadata.training.train_samples }} samples (40 Setosa, 40 Versicolor, 40 Virginica)
  • Testing Set: {{ metadata.training.test_samples }} samples (10 Setosa, 10 Versicolor, 10 Virginica)
  • Split Settings: test_size=0.2, random_state=42, stratify=y

Feature Scaling (StandardScaler)

Because KNN computes Euclidean distances, feature scaling is critical. The StandardScaler is fitted only on the training set to prevent data leakage, and applied consistently via a Pipeline.

z = (x − μtrain) / σtrain

K-Value Optimization (5-Fold Cross-Validation on Training Data)

Evaluated solely on training folds; test set remained untouched during hyperparameter tuning.
